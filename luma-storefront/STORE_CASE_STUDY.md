# LUMA Storefront — Case Study

I built LUMA, a polished mini e-commerce storefront with a bold navy, violet, coral, mint, and warm-yellow palette. The product listing fetches live products from Fake Store API and supports search and category filtering. The shopping cart uses React state and localStorage so products and quantities survive a refresh. Dynamic routing powers product detail pages, while checkout calculates subtotal, shipping, and the final total without real payment processing. I reused a small Week 5-style UI kit containing Button, Card, Modal, and Toast components across the storefront. Meaningful motion includes product hover scaling, card lift transitions, skeleton loading, and modal animation. With more time, I would add authentication, server-side cart persistence, pagination, automated tests, stronger retry handling, and a real payment provider.
